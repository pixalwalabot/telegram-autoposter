Bot Token aur Channel ID kaise milega? (2 Minute Setup)

  1. Telegram open karein, @BotFather search karein aur /newbot bhejein.
  2. Apne bot ka naam aur username set karein — BotFather aapko ek Bot Token dega (jaise 123456:ABC-DEF...). Use neeche Box 1 me paste karein.
  3. Apne Telegram Channel ke Administrators me jaakar apne naye bot ko add karein aur Post Messages on karein.
  4. Public channel ke liye @your_channel_username daalein. Private channel ke liye uski numeric ID (jaise -1001234567890) daalein.
  5. Neeche photos add karein, Test 1 Photo daba kar check karein, aur phir Start Auto-Posting chala dein.
