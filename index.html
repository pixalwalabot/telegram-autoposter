2 Minute Setup Guide

  1. Telegram me @BotFather par jaakar /newbot bhejein aur apna Bot Token copy karein.
  2. Apne Channel ke Administrators me bot ko add karein aur Post Messages ON karein.
  3. Bot Setup tab me Token aur @channel_username (ya Private ID) daal kar Save karein.
  4. Ab Schedule, Auto Photos, ya YouTube tab se seedha post karein!
